# 转换基线

Baseline 0.1.0。以下规则保持源文件到文档的可追溯关系；格式和领域差异写进 profile。

| ID | 规则 | 执行含义 |
|---|---|---|
| C01 | 实际输入为权威源 | 保留用户提供的字节，不能用库中同名文件替代。多文件工程记录入口和依赖。 |
| C02 | 事实、观察、假设分离 | 原生声明与计算结果进入 facts；可见外形进入 observation；用途推断标明未验证。 |
| C03 | 文档由规定契约生成 | 名称、字段、语言、目录和摘要规则由目标 profile 固定，用户规范优先。 |
| C04 | 每条证据有对象与版本 | 源、解析结果、图像、观察和文档绑定同一对象、输入快照和 profile。 |
| C05 | 未知必须保留 | unknown、unsupported、not_applicable 和已证明的空集合有不同含义。 |
| C06 | 预览来自真实输入 | 使用真实 CAD 导出/渲染，不以生成式图片或占位图替代几何证据。 |
| C07 | 视觉审阅真实发生 | 记录查看的图像和审阅者；reviewed 是实际动作的结果，不是通过门槛的填充值。 |
| C08 | 工具范围可核查 | 格式版本、实体类型、单位和依赖解析方法有依据；不支持的内容报告为缺口。 |
| C09 | 发布版本不可静默覆盖 | 同身份同版本字节不同即冲突；改变输入或规定正文时按版本策略生成新版本。 |
| C10 | 完成状态有实际检查 | 本地生成、合格交付、上传、可检索和回读通过分别有证据。 |

## 默认与可配置项

默认输出语言为中文；五类文档使用 UTF-8，JSON 使用标准 JSON。默认要求真实预览和视觉审阅，三维几何 profile 用米存储可计算长度并明确坐标系，展示单位可另设。二维工程、图纸或其他表示按对应 profile 调整量纲和观察对象。

这些默认不强制所有 CAD 具有三维包络、连接口、特定工具、特定文件扩展名或特定知识库。用户目标 schema 可以增加、合并或重命名文档；适配记录保留本基线的证据与语义分工。

## 本地文档化的完成边界

转换回答的是“源文件中声明/计算了什么，图像可见什么，以及这些内容如何进入规定文档”。源文件提供的材质、功能或额定参数应标为源声明。几何包络不能代替公差、装配间隙或工程性能；入库成功不能直接作为工程可用性证据。
