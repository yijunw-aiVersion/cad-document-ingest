# 格式与目标文档适配

## 输入适配器

适配器可以是已有 CLI、CAD 软件的 API、可用的文件库或软件导出功能；每次运行选择真实可用的方法，不假定包内有未实现命令。直接读取可靠的文本 CAD 也应记录提取规则和支持范围。

最少约定这些结果：实际源与依赖快照、身份/元数据、带单位坐标的事实、诊断、真实预览和执行回执。字段不支持时返回状态与理由。脚本提取与模型判断分工：脚本/API 管精确数字和绑定，Agent 管实际观察及有边界的语义归纳。

| 输入类型示例 | 应确认的能力 | 常见缺口 |
|---|---|---|
| STEP / IGES 等交换格式 | 格式版本、装配结构、单位、曲面/实体解析、变换和预览 | 语义接口、材料或参数历史不一定保留 |
| STL / OBJ 等网格格式 | binary/text 检测、顶点面、外部材质/纹理、单位依据 | 单位可能未声明；网格不自动提供实体精确尺寸或功能 |
| DXF / DWG 等绘图格式 | 实体类型、块/外部参照、图层、标注与尺度、版本支持 | 不支持实体、外部参照缺失、标注数值与实际几何不一致 |
| 原生参数化工程文件 | 可用软件/SDK、文档状态、依赖和配置、导出能力 | 专有版本、插件、抑制组件或未重算模型 |

这些是选择能力的例子，不是本包已经测试过的格式支持表。未配置可用后端时可完成 profile 和缺口记录，不能标记文件已成功转换。

## 适配必须记录的差异

- **对象边界**：一个文件、装配中的一个对象或多个文件共同定义的对象。不要把多文件工程强制压成一个“零件”。
- **身份与分类**：ID 的来源、类别声明/规则依据和重名处理。领域类别词表放入 profile，不写成通用内置类别。
- **单位与坐标**：源声明、规范化方式、轴方向、左右手系、2D/3D、局部/世界坐标与实际变换矩阵。单位未知时不能硬算米或毫米。
- **几何方法**：原生 B-rep 极值、网格包络、二维边界或其他量；公差、误差及支持实体范围。
- **接口证据**：原生声明、与同版源绑定的外部声明或 unknown。几何相似不能自动成为连接接口。
- **预览策略**：required / optional / not_applicable，实际工具、配置、视角、分辨率、对象隔离与遮挡。渲染色与真实颜色分别表述。
- **有损读取**：未知字段和不支持实体如何保存或诊断；保留原文件避免不可逆信息丢失。有损能力影响必需字段时不能通过对应门槛。

接口外部库与主源必须有明确版本/哈希绑定。主源改变时，不能仅因文件名相同就借用旧接口。

## 目标文档适配

用户指定 schema 时先列出本包逻辑角色到目标字段和文件的映射，再生成文档。必要字段、nullable 规则、枚举、语言、文件名、摘要长度和链接形式写进 profile。对用户要求的额外属性，先确认数据源；不能为填满表格而创造事实。

输入适配与目标适配分别版本化。换输入格式不需要改变五类文档职责；换目标文档 schema 不代表需要改变源解析规则。用户规范允许缺失字段时保留 reason；规范不允许而数据不可得时交付诊断，不能伪造合格文档。
